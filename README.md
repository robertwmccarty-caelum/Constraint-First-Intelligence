# Constraint-First Intelligence

Research notes on whether a system can preserve specified constraints when its underlying model changes.

## Reading the notes

- [Mathematical formulation](./math) defines the proposed projection.
- [Validation ladder](./validation) describes the evidence needed to support progressively stronger claims.
- [Model-swap experiment](./xmod) sketches a continuity test.

The default branch contains design notes and experiment fragments. The package layout described in the notes is proposed. Reproducing the experiments requires assembling the implementation and tests.
